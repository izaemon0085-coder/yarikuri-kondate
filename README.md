


# やりくり献立（仮）

1か月の献立を、**予算**と**近所のスーパーの特売品**から考えてくれるAIアプリです。

## 誰のためのアプリか

- 家族で暮らしている人
- 一人暮らしの人
- 毎日の献立を考えるのが大変な人、食費をおさえたい人

## 解決したいこと

- 毎日の献立を考えるのが面倒
- 食費が予算をオーバーしやすい
- 特売品を買っても、うまく使い切れない

## できること

### ベース版

- 人数・1か月の予算・苦手な食材・地域・特売品を入力する
- 期間（1日分 / 1週間分 / 1か月分）を選ぶ
- AIが朝・昼・夜の献立を作る（苦手な食材は使わず、特売品をできるだけ使う）
- 毎日の食費の目安と合計を表示する
- 合計が予算内か、予算オーバーかを色で表示する
- 人数や予算の入れ忘れ、APIキーや通信のエラーを、わかりやすいメッセージで知らせる

### ステップ2

- 献立を始める日を選ぶ
- 献立を「10/12(月)」のような日付つきの表で表示する。1か月分は「第1週」〜のタブで切りかえる
- 毎日の食費をプログラムで足して、予算と比べる
- よく行くお店を3つまで登録する
- お店ごとにチラシの写真を読み込むと、AIが特売品と値段を読み取って、特売品の欄に入れる
- AIが、どのお店で何を買うと安いかを考えて、お店ごとの買い物リストを表示する

### ステップ3

- 「買い物の記録」ページで、使った金額を記録する
- レシートの写真を読み込むと、AIが日付・お店・商品・値段を読み取る
- 商品を区分（食材・飲み物・お酒・お菓子・日用品・その他）に分ける
- 写真がなくても、手で入力できる。読み取った結果も、手で直せる
- 表の並べ方を選べる（レシートの順・あいうえお順・区分ごと・値段の高い順・安い順）。区分の順番も自分で決められる
- 記録はパソコンの中のファイル（`kaimono.csv`）に保存する。間違えた記録は消せる
- 今月の区分ごと・お店ごとの合計を出す
- 食材と飲み物の合計を食費の予算と比べて、残りの金額と、1日あたりに使える金額を出す
- 予算をこえそうなときは、警告ではなく、AIが「安く済ませる案」を出す

## 使い方

### 1. 準備（最初の1回だけ）

必要なもの：

- Python 3.13
- Git
- AnthropicのAPIキー（[Claude Console](https://console.anthropic.com/settings/keys) で作成）

PowerShellで、1行ずつ実行します。

```powershell
git clone https://github.com/izaemon0085-coder/yarikuri-kondate.git
cd yarikuri-kondate
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

`yarikuri-kondate` フォルダに `.env` というファイルを作り、次の1行を書きます。

```
ANTHROPIC_API_KEY=ここに自分のAPIキー
```

> `.env` は `.gitignore` に入っているので、GitHubには上がりません。APIキーは誰にも見せないでください。

### 2. 起動する

```powershell
cd yarikuri-kondate
.\.venv\Scripts\Activate.ps1
python -m streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。止めるときは、ターミナルで `Ctrl` + `C` を押します。

画面の左のメニューで、ページを切りかえます。

| メニュー | ページ |
|---|---|
| `app` | 献立を作る（下の3・4） |
| `買い物の記録` | 使った金額を記録する（下の5〜7） |

> `streamlit run app.py` で起動しないとき（Windowsのアプリ制御に止められるとき）も、`python -m streamlit run app.py` なら起動できます。

### 3. お店と特売品を入れる

1. 人数と1か月の食費の予算を入力する（必須）
2. 苦手な食材・アレルギー、地域を入力する（任意）
3. 「よく行くお店の数」を選ぶ（1〜3）
4. お店ごとに、名前を入力する（例：`〇〇ストア 駅前店`）
5. 特売品を入れる。次のどちらでもできます
   - **チラシの写真から**：写真（JPG・PNG）を選んで「お店1のチラシを読み取る」を押すと、AIが読み取って特売品の欄に入れます。読み取ったあとに、手で直すこともできます
   - **手で入力**：1行に1つずつ入力します（例：`豚こま 100g 98円`）

> チラシではない写真のときは「特売品が見つかりませんでした」と出ます。

### 4. 献立を作る

1. 期間（1日分 / 1週間分 / 1か月分）を選ぶ
2. 献立を始める日を選ぶ
3. 「献立を作る」を押す

画面には、次の順番で表示されます。

1. 予算内か、予算オーバーか（合計と目安の金額）
2. 献立の表（日付・朝・昼・夜・食費）。1か月分は「第1週」〜のタブを押して切りかえます
3. お店ごとの買い物リスト。買うものと、そのお店にした理由（例：`88円で一番安い`）が出ます

1日分は数秒〜30秒、1か月分は1分半ほどかかります。チラシの読み取りにも少し時間がかかります。AIを使うたびに料金がかかるので、ボタンは1回だけ押してください。

### 5. 買い物を記録する（「買い物の記録」ページ）

1. 次のどちらかで、買ったものを表に入れる
   - **レシートの写真から**：写真（JPG・PNG）を選んで「レシートを読み取る」を押す。AIが日付・お店・商品・値段・区分を読み取ります
   - **手で入力**：「写真なしで、新しく手で入力する」を押して、表の下の「＋」で行を足す
2. 表のマスをダブルクリックすると、商品・値段・区分を直せます。区分は一覧から選ぶだけです
3. 日付とお店を確かめて、「記録する」を押す

> レシートではない写真のときは「レシートが見つかりませんでした」と出ます。

### 6. 並べ方を変える

左のサイドバーの「並べ方」で、表の並べ方を選べます。

- レシートの順 / あいうえお順 / 区分ごと / 値段の高い順 / 値段の安い順
- 「区分ごと」のときは、「区分の順番」で好きな順番に選べます（例：お酒 → 食材 → 日用品）。選ばなかった区分は後ろに並びます

### 7. 今月の記録と予算を見る

ページの下のほうに、次のものが出ます。

1. **今月の記録**：消したい記録は、表の左はしをクリックして選び、「選んだ記録を消す」を押します
2. **区分ごとの合計**と**お店ごとの合計**
3. **食費の予算**：1か月の食費の予算を入れると、予算・使った食費（食材＋飲み物）・残りの金額と、1日あたりに使える金額が出ます

このままのペースで予算をこえそうなときは、「安く済ませる案を、AIに聞く」ボタンが出ます。押すと、AIが今月の記録を見て、安い食材への置きかえ・安いお店・安い食材を使った料理などの案を出します。

> 記録は `yarikuri-kondate` フォルダの `kaimono.csv` に保存されます。家計の情報なので、`.gitignore` に入れてGitHubには上げません。エクセルでも開けます（開いたまま記録すると保存に失敗することがあるので、見終わったら閉じてください）。

## 使っている技術

- Python 3.13
- Streamlit（入力欄やボタンのある画面。`pages` フォルダで複数のページを作る）
- Anthropic Claude API（Claude Opus 5.5。献立と食費を考える、チラシとレシートの写真を読む、安く済ませる案を考える）
- python-dotenv（`.env` からAPIキーを読み込む）
- pydantic（AIの答えを、日付・朝・昼・夜・食費などの決まった形で受け取る）
- pandas（献立や記録を表にする。合計を出す。記録を `kaimono.csv` に保存する）
- Pillow（チラシやレシートの写真を小さくしてからAIに送る）
