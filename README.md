# やりくり献立（仮）

1か月の献立を、**予算**と**近所のスーパーの特売品**から考えてくれるAIアプリです。

## 誰のためのアプリか

- 家族で暮らしている人
- 一人暮らしの人
- 毎日の献立を考えるのが大変な人、食費をおさえたい人

## 解決したいこと

- 毎日の献立を考えるのが面倒
- 食費が予算をオーバーしやすい
- 特売品を買っても、うまく使い切れない

## できること（ベース版）

- 人数・1か月の予算・苦手な食材・地域・よく行くスーパー・特売品を入力する
- 期間（1日分 / 1週間分 / 1か月分）を選ぶ
- AIが朝・昼・夜の献立を作る（苦手な食材は使わず、特売品をできるだけ使う）
- 毎日の食費の目安と合計を表示する
- 合計が予算内か、予算オーバーかを色で表示する
- 人数や予算の入れ忘れ、APIキーや通信のエラーを、わかりやすいメッセージで知らせる

## 使い方

### 1. 準備（最初の1回だけ）

必要なもの：

- Python 3.13
- Git
- AnthropicのAPIキー（[Claude Console](https://console.anthropic.com/settings/keys) で作成）

PowerShellで、1行ずつ実行します。

```powershell
git clone https://github.com/izaemon0085-coder/yarikuri-kondate.git
cd yarikuri-kondate
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

`yarikuri-kondate` フォルダに `.env` というファイルを作り、次の1行を書きます。

```
ANTHROPIC_API_KEY=ここに自分のAPIキー
```

> `.env` は `.gitignore` に入っているので、GitHubには上がりません。APIキーは誰にも見せないでください。

### 2. 起動する

```powershell
cd yarikuri-kondate
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。止めるときは、ターミナルで `Ctrl` + `C` を押します。

### 3. 献立を作る

1. 人数と1か月の食費の予算を入力する（必須）
2. 苦手な食材・アレルギー、地域、よく行くスーパーを入力する（任意）
3. 特売品を1行に1つずつ入力する（例：`豚こま 100g 98円`）
4. 期間（1日分 / 1週間分 / 1か月分）を選ぶ
5. 「献立を作る」を押す

1日分は数秒〜30秒、1か月分は1分半ほどかかります。AIを使うたびに料金がかかるので、ボタンは1回だけ押してください。
