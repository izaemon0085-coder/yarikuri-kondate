# やりくり献立（仮）

1か月の献立を、**予算**と**近所のスーパーの特売品**から考えてくれるAIアプリです。

## 誰のためのアプリか

- 家族で暮らしている人
- 一人暮らしの人
- 毎日の献立を考えるのが大変な人、食費をおさえたい人

## 解決したいこと

- 毎日の献立を考えるのが面倒
- 食費が予算をオーバーしやすい
- 特売品を買っても、うまく使い切れない

## ベース（最初に作るもの）

「入力 → AIが献立を作る → 表示」がひと通り動くことを目指します。

### 入力するもの

| 項目 | 例 |
|---|---|
| 人数 | 1人 / 4人 |
| 1か月の食費の予算 | 50,000円 |
| 苦手な食材・アレルギー | えび、セロリ |
| 地域 | 東京都 世田谷区 |
| よく行くスーパー | 〇〇ストア 駅前店 |
| 特売品（手入力） | 豚こま 100g 98円、キャベツ 1玉 128円 |

### 出てくるもの

- 1か月分の献立（朝・昼・夜）
- 1日・1週間ごとの食費の目安
- 予算内に収まっているかどうか

## 使い方のイメージ

1. 「4人家族・月5万円・えびアレルギー」と入力する
2. 地域とよく行くスーパーを登録する
3. 「今週の特売：豚こま98円、キャベツ128円」と入力する
4. AIが1か月の献立と、食費の目安を表示する

## これから追加したい機能

| 段階 | 機能 |
|---|---|
| ステップ2 | チラシの写真から、AIが特売品と値段を読み取る / どのお店で買うと安いかを表示する |
| ステップ3 | お店ごとの買い物リスト / 使った金額の記録と、予算との比較 |
| ステップ4（発展） | 同じ地域の人と特売情報を共有する |

## 使う技術（予定）

- Python
- Streamlit（入力欄やボタンのある画面を作る）
- AIのAPI（献立と食費を考える）

※講座の指定があれば、それに合わせて変更します。
